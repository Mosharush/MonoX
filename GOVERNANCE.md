# Governance

MonoX is currently maintained by Moshe Harush.

Changes are accepted through reviewable pull requests. Security, schema compatibility and release provenance
take priority over feature volume. Maintainer decisions should be recorded in issues, pull requests or
architecture decision records so contributors and coding agents can understand the reason behind a rule.

The project may add maintainers after sustained, trusted contributions. Package publication, repository
visibility and deployment automation remain maintainer-approved operations.
